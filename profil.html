Connecter GitHub
  1. Ouvre GitHub › Nouveau jeton (fine-grained).
  2. Nom : Éditeur de poses NSF. Expiration : au choix (par exemple 1 an).
  3. Repository access : « Only select repositories » › cameleon-ds/nitro-surge-fighters. Si le dépôt appartient à une organisation, choisis-la dans « Resource owner ».
  4. Permissions › Repository permissions › Contents : Read and write. Rien d'autre.
  5. Clique sur Generate token, copie le jeton (il commence par github_pat_) et colle-le ci-dessous.
Le jeton est vérifié puis gardé côté serveur : il n'est jamais renvoyé au navigateur.
